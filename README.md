# WDS Wormhole ID

Visual wormhole identification trainer. Public, no auth.

- **URL:** https://id.deliverynetwork.space
- **Port:** 3015
- **Server path:** `/opt/wds-wormhole-id` on `10.0.0.33`
- **Service:** `wds-wormhole-id.service`
- **Tunnel:** main tunnel `3ab5ab83-18f0-4101-903c-9a0601c30964`

Static SPA served by a minimal Express wrapper. Images hotlinked from
[wiki.eveuniversity.org](https://wiki.eveuniversity.org/Visual_wormhole_identification).

## Modes

1. **Class ID** &mdash; C1&ndash;C6 + Thera from the connection nebula
2. **Mass Class** &mdash; aurora flare colour (frigate / small / large / massive)
3. **Region ID** (advanced) &mdash; two stages: empire, then region
